
# Go Testing Mastery

A practical journey from beginner to advanced Go testing.

## Learning Objectives

- Master Go's testing package.
- Write maintainable unit tests.
- Test HTTP APIs and middleware.
- Understand mocks and integration testing.
- Test concurrent applications.
- Write benchmarks and fuzz tests.
- Build production-ready testing workflows.

## Roadmap

1. Testing Fundamentals
2. Unit Testing
3. Advanced Testing
4. HTTP Testing
5. Integration Testing
6. Mocking
7. Concurrency Testing
8. Benchmarking
9. Fuzz Testing
10. Production Testing

## Running Tests

Run all tests:

```bash
go test ./...
```

Run with verbose output:

```bash
go test -v ./...
```

Run with race detection:

```bash
go test -race ./...
```
